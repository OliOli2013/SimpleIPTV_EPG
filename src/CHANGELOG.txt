Simple IPTV EPG - 3.1.0-r1 (09.10.2026)
======================================
PL
- Poprawiono wywołanie eEPGCache.importEvents: lista referencji zamiast pojedynczego stringa.
- Dodano automatyczne wykrywanie źródeł BouquetMakerXtream z /etc/epgimport.
- Dodano odczyt oryginalnego mapowania XMLTV ID → rzeczywista referencja IPTV.
- Zachowano zgodność referencji dla różnych silników (4097 / 5001 / 5002).
- Zapobiegnięto nadpisywaniu mapowania BMX błędnym dopasowaniem po nazwie.
- Dodano rozpoznawanie kompresji GZIP niezależnie od rozszerzenia URL.
- Poprawiono ograniczenie zużycia pamięci przy odczycie dużych XMLTV.
- Dodano diagnostykę BMX i weryfikację widoczności EPG na próbce usług.
- Dodano ochronę przed ujawnianiem danych dostawcy w logach.
- Zabezpieczono aktualizator przed niezamierzonym cofnięciem wersji.
- Zachowano nazwę pakietu, konfigurację użytkownika i ścieżkę AIO Panel.

EN
- Fixed eEPGCache.importEvents invocation: sequence of service refs, not a bare string.
- Added BouquetMakerXtream sources.xml discovery and channel-id mapping.
- Supports IPTV service-type differences while preserving original bouquet refs.
- Native BMX ID mappings take precedence over fuzzy service-name matches.
- Detects compressed XMLTV by magic bytes, even for PHP endpoint URLs.
- Bounded XMLTV memory usage, new diagnostics and on-device EPG visibility sampling.
- Redacts provider credentials; protects the updater against downgrades.
- Preserves AIO Panel package ID, settings, paths and project branding.

NOTE: Tested offline with synthetic IPTV/XMLTV fixtures. Test on Enigma2 tuner before production rollout.
